# discord-handler
 Node.JS version 16.9.0 or higher (prefer latest LTS version). This repository is a basic template to get started your Discord "App" in Discord.JS v14.

## Configuration

1. Run `npm install`.
2. Copy `.env.example` to `.env` and set `DISCORD_TOKEN` to your Discord bot token.
3. Keep `.env` private; it is excluded from Git. Never commit tokens, passwords, or API keys.
